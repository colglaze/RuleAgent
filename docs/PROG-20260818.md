## 实施中发现并解决的问题

- DeepSeek V4 默认启用 thinking。长规则首次验收出现 HTTP 200 但结构化内容为空；依据官方 thinking 配置关闭推理模式后，两份业务文档稳定返回 JSON 候选。
- 真实规则包含带追溯表达式的谓词和带内部筛选条件的存在性判断。条件 AST 在不放松事实引用校验的前提下，明确支持 `predicate.expression/factRefs` 与 `exists.children`，随后补齐回归测试。
