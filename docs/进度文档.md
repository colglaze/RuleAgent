## 当前状态

Phase 0 文档基线、Phase 1.0 后端骨架和 Phase 1.1-1.5 规则解析闭环均已完成。项目运行时锁定为 Python `3.11.9`，依赖管理采用 `venv + pip + pyproject.toml`，Agent 编排框架为 LangGraph，模型供应商为 DeepSeek。

后端现已具备 FastAPI/Uvicorn 服务、集中配置、脱敏配置检查、PyMongo Async 生命周期、MongoDB Schema v2 幂等迁移、健康检查和自动化测试。Rule Parsing Agent 已实现 camelCase JSON 契约、确定性语义校验、四视图字段目录、LangGraph 有限重试图、DeepSeek JSON Output 适配器、受控 Markdown 读取、HTTP 文本入口和 CLI 文件入口；规则版本仓储支持显式不可变保存与精确版本回读。

Phase 1.6 已按用户授权完成：增加显式、不可变的 MongoDB 草稿版本归档，并保存一版《项目报告释放规则》。规则仍固定为待人工审核的 `draft` 且不可执行；Wiki、Agent 2、审批发布和执行链路继续不实现。
