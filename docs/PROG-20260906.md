本任务代码与测试改动（离线全绿后才发起新一轮真实调用）：

- `infrastructure/deepseek.py`：SYSTEM_PROMPT 新增 10b（判空必须一元 isNull/isNotNull/isBlank/
  isNotBlank 且禁止携带 right，literal.value 禁止 null/含 null 数组）、10c（requiredFacts 必须
  进入条件/派生引用闭包）、10d（日期边界用 `runtime.current_date` 与 `dateAdd(日期事实, 整数,
  day)` 同型比较）、10e（测试案例 given 必须覆盖路径全部事实，缺失即 indeterminate）。
- `application/rule_parsing/workflow.py`：`PROMPT_VERSION` v6 → `rule-parser-v8`。
- `domain/rules/validation_v2.py`：案例求值不符且结果为 indeterminate 时，在错误明细中追加
  `missing given values: [...]`（引用闭包内未给值的叶子事实）与
  `null given values under indeterminate nullPolicy: [...]`，使重试反馈可定位。先写 2 个失败
  测试确认红态再实现（`test_rule_domain_v2.py` 新增 2 例，归属本任务，非用户自行添加）。
