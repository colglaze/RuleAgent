### 1.2 工程骨架与领域校验

状态：`COMPLETE`（2026-08-18）

- 根据 DEV 创建锁定 Python `3.11.9` 的最小工程和测试结构。

- 不接入真实模型或外部系统。

DoD：默认测试离线通过，非法候选不会形成有效草稿。

### 1.3 本地文档适配器

状态：`COMPLETE`（2026-08-18）

- 实现受控目录读取、编码处理、路径安全和内容哈希。

DoD：正常与文件错误场景均有自动化测试，无法读取的文档不会调用模型。

### 1.4 模型解析适配器

状态：`COMPLETE`（2026-08-18）

- 接入 DEV 确认的 DeepSeek 模型和结构化输出策略。
- 使用 LangGraph 串联文档读取、模型解析、Schema 校验、语义校验和错误路由。
- 实现超时、限流、空响应、非法 JSON 和有限重试。
- 使用测试替身覆盖默认测试，真实 Provider 测试显式启用。

DoD：模型候选必须经过两级校验；所有 Provider 失败路径以及 LangGraph node、edge 和终止 state 可重复验证。

DoD：代表性本地 Markdown 可以端到端转换为可校验草稿；失败不留下有效产物；进度文档有完整证据。
